সাধারণ প্রশ্ন (FAQ)

Affiliate Program সম্পর্কে যা জানতে চান

প্রথমে Opascript-এ একটি Account তৈরি করুন। তারপর Client Dashboard-এ Login করে "Affiliate Program" সেকশনে যান এবং Application জমা দিন। Admin Approval সাধারণত ২৪ ঘণ্টার মধ্যে হয়।
আপনার Referral Link দিয়ে কেউ Register করলে, এবং পরে সে একটি Order সফলভাবে Place ও Pay করলে, Admin সেই Order-এর জন্য Commission Record করেন। Commission তখনই আপনার Wallet-এ যোগ হয়।
Minimum ৳৫০০ হলে Withdrawal Request করা যাবে। Payment করা হয় bKash, Nagad, Rocket, বা Upay-এর মাধ্যমে।
Affiliate Approval-এর পরে Client Dashboard-এর "Affiliate Program" সেকশনে আপনার unique Referral Code ও shareable Link পাবেন। Link-টি Copy করে যেকোনো জায়গায় Share করুন।
আপনার Referral Code আপনার Account Active থাকা পর্যন্ত কাজ করবে। কেউ যখনই আপনার Link দিয়ে Register করবে, তার সব ভবিষ্যত Order-এর Commission আপনি পাবেন।
বর্তমানে Commission Rate ১০%। ভবিষ্যতে Top Affiliates-দের জন্য বিশেষ Rate বা Bonus দেওয়ার পরিকল্পনা আছে। যেকোনো পরিবর্তন আগে থেকে জানানো হবে।
